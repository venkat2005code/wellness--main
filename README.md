# VitalPulse Corporate Wellness — Complete Website

Converted from the supplied Stitch screens using HTML, CSS and vanilla JavaScript.

## Pages
- index.html — Enterprise Corporate Wellness
- home-2.html — Employee Culture & Engagement
- employee-dashboard.html — Employee Wellness Hub
- pricing.html — Enterprise Pricing
- programs.html — Wellness Program Catalog
- admin-dashboard.html — HR / Client Portal
- case-studies.html — Clinical Outcomes & ROI
- clinics.html — On-site Screenings & Workshops
- about.html — VitalPulse mission and approach
- contact.html — Enterprise, clinic, and employee contact pathways
- login.html — Sign-in screen; authentication requires a provider and is not enabled yet

## Global functionality
- Light/dark theme toggle
- RTL/LTR toggle
- Both settings persist across all pages using localStorage
- Cross-page navigation
- Same-page smooth scrolling
- Responsive behavior inherited from Stitch
- Basic client-side form validation and success feedback

## Run
Open index.html, or run:
python -m http.server 5500
Then visit http://localhost:5500
